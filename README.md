# موقع الشخصية العامة

## تشغيل
```
npm install
npm run dev
```
بدون Supabase يعمل الموقع ببيانات تجريبية. للربط:
1. أنشئ مشروعاً في Supabase وشغّل `supabase/schema.sql` في SQL Editor.
2. انسخ `.env.example` إلى `.env` وضع الرابط والمفتاح.
3. أنشئ مستخدماً من Authentication → Users، ثم نفّذ:
   `insert into admins (user_id) values ('UUID');`
4. لوحة التحكم: `/admin`

## التعديل
- بيانات الشخصية والروابط: `src/config/site.js`
- الأرقام والكلمة الترحيبية والسيرة: لوحة التحكم ← الإعدادات

## إشعارات تلغرام للطلبات الجديدة
1. في تلغرام افتح @BotFather ← `/newbot` ← احفظ **التوكن**.
2. أنشئ مجموعة للمكتب وأضف البوت إليها، ثم أرسل أي رسالة فيها.
3. افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخذ قيمة `chat.id` (تكون سالبة للمجموعات).
4. شغّل `supabase/telegram.sql` في SQL Editor، ثم نفّذ الـ insert الموجود بآخره بالتوكن والـ chat id.
5. أي طلب جديد من الموقع سيصل للمجموعة فوراً برقم المتابعة وبيانات المواطن.
> التوكن يُخزَّن في جدول محمي لا يقرأه الموقع، ولا تضعه في ملف `.env` ولا في الكود.
